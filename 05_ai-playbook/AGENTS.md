# AGENTS.md

Docs-only repo: **AI Engineering Playbook** — practical guide for engineers adopting AI tools.

## Layout

- `README.md` — entry point and contents table
- `AMBASSADORS.md` — contributor credits
- `docs/N. Title (UA).md` — one chapter per file
- `docs/AI Engineering Playbook — Plan.md` — authoritative outline and scope

## Writing rules

- **Language:** Ukrainian drafts, marked `(UA)` in the filename. English edition comes later, only after UA is finalized.
- **One section = one file.** Do not merge chapters.
- **Hints** as blockquote: `> 💡 **Hint:** …` — distinguishes recommendations from normative rules.
- **No horizontal rules (`---`)** between chapters or sections; rely on heading hierarchy.
- **Tone:** practical, decision-oriented, concise. No filler, no marketing language, no storytelling.
- Use the `engineering-playbook-author` skill for structure and quality gates when drafting or refining chapters.

## Don't

- Don't add code, configs, or build files — this repo is documentation only.
- Don't translate chapters to English until the UA version is approved.
- Don't invent contributors, quotes, or attributions — verify against `AMBASSADORS.md`.
- Don't edit `docs/AI Engineering Playbook — Plan.md` scope without an explicit request.
