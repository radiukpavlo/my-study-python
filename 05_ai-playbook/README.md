# AI Engineering Playbook

A practical guide for engineers on working effectively with AI tools — covering philosophy, tool selection, setup, context engineering, core workflow, prompt library, and anti-patterns.

> **Note:** The current draft is written in Ukrainian (filenames marked `(UA)`). An English edition will follow once the Ukrainian version is finalized.

## Contents


| #   | Section                                                                                        | What you'll learn                                                              |

| 2   | [Tool Selection](docs/2. Tool Selection (UA).md)                                               | Which tools to use and why — Cursor, Claude Code, Copilot; model selection     |
| 3   | [Tool Setup](docs/3. Tool Setup (UA).md)                                                       | Installation, configuration, and verification                                  |

| 6   | [Prompt Library](docs/6. Prompt Library (UA).md)                                               | Real prompts organized by task type                                            |
| 7   | [Anti-pattern Catalog](docs/7. Anti-pattern Catalog (UA).md)                                   | What does not work, and what to do instead                                     |


The playbook also includes four appendices: [Glossary](docs/Appendix A. Glossary (UA).md), [Resources](docs/Appendix B. Resources (UA).md), [Stack-Specific Notes](docs/Appendix C. Stack-Specific Notes (UA).md), and [Metric Baseline](docs/Appendix D. Metric Baseline (UA).md).

## Who This Is For

Engineers who want to integrate AI tools into their daily development workflow. The playbook assumes no prior AI tooling experience — it starts from first principles and builds up to a complete workflow.

## Contributors

The playbook is built on the practical experience of engineers who shared their workflows, tooling setups, and lessons learned.
